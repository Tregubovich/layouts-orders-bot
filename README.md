# Layouts Orders Bot

Telegram-бот для приёма заказов на изготовление архитектурных макетов.

[Ссылка на бота](http://t.me/layouts_orders_bot)

## Возможности

* пошаговый сбор требований к макету;
* расчёт предварительной стоимости заказа;
* формирование диапазона минимальной и максимальной цены;
* сохранение заказов;
* подтверждение или отмена заказа пользователем.

## Технологии

* **Go**
* **Telegram Bot API**
* **SQLite**
* **Redis**

## Запуск

Перед запуском установите необходимые переменные окружения:

```
export TG_BOT_TOKEN="your_bot_token"
export DATABASE_PATH="./data/sqlite/storage.db"
```

После этого запустите приложение:

```
go run ./cmd/...
```

Для запуска тестов:

```
go test ./...
```

## Цель

Проект предназначен для автоматизации первичной оценки стоимости архитектурных макетов.

Бот позволяет быстро собрать основные параметры заказа и предоставить клиенту предварительную стоимость без необходимости ручного расчёта на первом этапе.
